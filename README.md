# Daily Expense Tracker

## 📖 Overview

Daily Expense Tracker is a simple web application designed to help users record and manage their daily expenses. It provides an easy way to organize spending, monitor financial activities, and keep track of personal expenses through a clean and responsive interface.

## ✨ Features

- Add daily expenses
- Track spending records
- Simple and responsive UI
- Easy-to-use interface
- View expense details
- Lightweight and fast

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```
Daily-Expense-Tracker/
│── index.html
│── exp.css
│── exp.js
│── README.md
```

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/sangitnipurte/Daily-Expense-Tracker.git
```

2. Open the project folder.

3. Launch `index.html` in any web browser.
